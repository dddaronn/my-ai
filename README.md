# my-ai

Мини-библиотека для запросов к ИИ через облачный API (OpenAI-совместимый).
Есть резервный режим: гнать запрос через телефон (на случай блокировки сайта у провайдера ПК).

## Установка

На любом ПК:

```bash
pip install git+https://github.com/ТВОЙ_АККАУНТ/my-ai
```

## Использование

1. Создай рядом со своим скриптом файл `api_key.txt` и вставь туда свой ключ (одной строкой).
2. В коде:

```python
import my_ai
otvet = my_ai.ask("Привет, как дела?")
print(otvet)
```

> Вместо файла можно задать ключ через переменную окружения `AI_API_KEY`.

## Настройки (в начале `my_ai.py`)

| Параметр | Что это |
|----------|---------|
| `BASE_URL` | Адрес провайдера, напр. `https://moduleapi.pro/v1` |
| `MODEL` | Название модели, напр. `deepseek-v4-flash` |
| `USE_PHONE` | `False` — ПК сам в интернет; `True` — через телефон-мостик |

## Режим через телефон

Файл `phone_bridge.py` копируется на телефон (Pydroid/Termux), туда вписывается ключ и запускается.
ПК переключается в `USE_PHONE = True`. Телефон сам находит ПК в USB-сети (`PC_IP = "auto"`).

## ⚠️ Безопасность

Файл `api_key.txt` **никогда** не попадает в репозиторий (он в `.gitignore`).
Не вставляй настоящий ключ в `phone_bridge.py` перед заливкой на GitHub.
